What is C?

C is a procedural language used to develop efficient software.

Key concepts

  • Variables and data types
  • Operators and conditions
  • Loops and functions
  • Arrays and pointers

What can it build?

Calculators, simple games and system utilities.

Example

    printf("Hello World!");
    return 0;

SQL

What is SQL?

SQL stands for Structured Query Language. It is used to retrieve, insert, update and manage database records.

Key concepts

  • Creating databases and tables
  • SELECT, INSERT, UPDATE and DELETE
  • WHERE and ORDER BY
  • GROUP BY and aggregate functions
  • INNER JOIN and other JOIN operations
  • Primary and foreign keys

What can it build?

Student records, inventory systems and sales reports.

Example

SELECT *
FROM Student
ORDER BY StudentName ASC;

This example assumes your table contains a StudentName column.
